# Game Recommendation Finder

## Project Description

Game Recommendation Finder is a Python console application that recommends video games based on a user's preferred genre. The program loads game data from a JSON file, searches for matching games, and displays recommendations to the user.

This project was created as a capstone project to demonstrate Python programming concepts learned throughout the course.

---

## Features

- Load game data from a JSON file
- Search games by genre
- Display recommended games
- Validate user input
- Handle file and data errors
- Allow multiple searches in one session

---

## Technologies Used

- Python 3
- JSON data storage

---

## Files Included

- `main.py` - Main application code
- `game_data.json` - Stores game information
- `README.md` - Project documentation

---

## How to Run the Program

1. Make sure Python 3 is installed.
2. Place `main.py` and `game_data.json` in the same folder.
3. Open a terminal or command prompt.
4. Navigate to the project folder.
5. Run:

```bash
python main.py
